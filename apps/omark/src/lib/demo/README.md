# The demo world

Maya's files for the one app's demo build (one app spec, section 9): `world.ts` writes them, `open.ts` keeps them in IndexedDB, `accounts.ts` opens them in the shell.

`health.jpg` and `home.jpg` are the pictures of the *Health* and *Home* areas: original flat illustrations made for this repository by Claude, rendered with Playwright. They are dedicated to the public domain (CC0 1.0). Only the demo build has them: `vite.config.ts` copies them to `demo/`.
