# The demo world

Maya's files for the one app's demo build (one app spec, section 9): `world.ts` writes them, `open.ts` keeps them in IndexedDB, `accounts.ts` opens them in the shell.

The pictures of the four areas are photos from StockSnap, dedicated to the public domain (CC0 1.0), resized to 960x640 (#155). Only the demo build has them: `vite.config.ts` copies them to `demo/`.
