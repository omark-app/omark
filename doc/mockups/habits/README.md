# Habits and settings mockups

Source of the mockup canvas for the [habits spec](../../tasks/habits-spec.md) (#44) and the [settings page spec](../../Omark%20settings%20page%20spec.md) (#45), approved 2026-10-26.

View them at https://claude.ai/artifact/VwN7ULDERA3tsd2JoMatWt (AL's claude.ai account). These files are a copy of that canvas, kept so the design survives with the specs; they need the canvas runtime and don't open as plain pages.

| File | Shows |
|---|---|
| `Main.dc.html` | Desktop task list: habit rows in the buckets, the Habits group above Important, not urgent |
| `Phone.dc.html` | Phone: habit cards at the top, habit rows, the tick toast |
| `RowStates.dc.html` | One habit row in each state, the formed toast, the limit toast |
| `Detail.dc.html` | The habit block in the task detail (count, last 28 periods, misses) |
| `History.dc.html` | In progress, Formed, Dropped |
| `Settings.dc.html` | The settings page, Habits section included |
| `canvas.json` | The canvas layout |

Where the mockups and the specs disagree, the specs win.
